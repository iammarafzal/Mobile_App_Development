# Mobile Application Development

This repository contains all code files and projects created for the Mobile Application Development course at university.

## Course Projects

- `Lab-01/` - introductory Flutter applications
- `Lab-02/` - forms, navigation, and gesture detection examples
- `Lab-03/` - multi-screen navigation, grid views, and API integration with list views

Each project is a standalone Flutter application with its own dependencies and platform-specific files.
